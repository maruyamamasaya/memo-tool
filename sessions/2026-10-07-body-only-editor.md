# Body-only Web editor

## Request
Webの編集画面を本文のみとし、1行目からタイトルを自動生成する。ユーザー確認によりタグ欄の廃止は入力画面のみ。

## Investigation
タイトル・タグ・本文はFirestoreの独立フィールド。Rulesは空でない120文字以内のタイトルを要求する。既存タグと分類は本文編集でも保持する必要がある。

## Changes
独立タイトル・タグ欄と編集オプションを撤去。全文をそのまま保存し、1行目からタイトルを生成。既存独立タイトルは本文先頭へ引き継ぎ、自動タイトルは重複させない。一覧のタグ操作と設定は継続。入力とCSS/JSのキャッシュ識別子、利用・構造文書を更新。

## Validation
静的検証、Nodeテスト8件、Markdownリンク検証、diff確認。Windowsのpython3不足によりverify.sh相当の各チェックを直接実行。
ローカルHTTP配信とEdgeの1280×800、700×700、390×844、320×568、844×390で本文のみのUI、新規入力、自動保存、既存メモ編集、Escape保存を確認。Firestore関数を代替して保存payloadの全文・自動タイトル・タグ/分類保持を検証。本番Firebaseへの書き込みは未実施。

## Result
本文のみの編集UIを実装。

## Remaining Issues
本番のログイン・保存は実データ環境で未検証。
